At the core of a Mixture-of-Experts (MoE) architecture is a lightweight gating network, often a simple linear layer, that evaluates the input representation for each token. This network calculates a set of scores or probabilities for every available expert, effectively determining how relevant each specialized sub-model is to the current context. These scores reflect the likelihood that a specific expert will produce the most accurate output for that particular token.

Once the scores are computed, the model employs a routing strategy to select only a small subset of experts, typically the top-k highest-scoring ones, to process the token. This sparse activation ensures computational efficiency by avoiding the need to run all experts for every input. The selected experts then process the token in parallel, generating their respective outputs, while the non-selected experts remain inactive, saving significant computational resources.

Finally, the outputs from the active experts are combined using a weighted sum, where the weights correspond to the normalized scores assigned by the gating network. This aggregation step blends the specialized knowledge of the chosen experts into a single, coherent output vector. The result is then passed to the next layer of the transformer, allowing the model to leverage diverse expertise dynamically without incurring the full cost of a dense model.
