A mixture-of-experts (MoE) model begins by processing the input token through a lightweight component known as a gating network or router. This router analyzes the token's embedding and calculates a set of scores representing how relevant each specialized expert sub-network is to the current context. These scores essentially act as a probability distribution, indicating which experts are best suited to handle the specific linguistic patterns or semantic nuances of that particular token.

Once the scores are generated, the model employs a selection strategy to determine which experts will actually perform the computation. In most modern architectures, this involves a "top-k" selection, where only the experts with the highest scores are activated, while the rest remain dormant. This sparse activation ensures computational efficiency, as the model does not need to run every expert for every token, thereby keeping the inference cost manageable despite the large total number of parameters.

Finally, the outputs from the selected experts are combined to produce the final representation for that token. This combination is typically a weighted sum, where each expert's output is multiplied by its corresponding normalized score from the gating network. This allows the model to blend insights from multiple specialized experts, leveraging their collective knowledge to generate a more accurate and context-aware prediction than any single expert could achieve alone.
