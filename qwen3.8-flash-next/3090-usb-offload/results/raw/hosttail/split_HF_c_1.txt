At the core of a Mixture-of-Experts (MoE) architecture is a lightweight gating network, often a simple linear layer, that evaluates the input representation for each token. This network calculates a set of scores or logits corresponding to every available expert in the model. These scores represent how relevant or suitable each specific expert is for processing the current token's context, effectively acting as a router that determines the best path for the data.

Once the scores are computed, the model typically employs a top-k selection strategy, where only the experts with the highest scores are activated for that specific token. This sparse activation ensures computational efficiency, as the model does not need to run all experts for every input. The selected experts then process the token in parallel, generating their respective outputs, while the non-selected experts remain idle, saving significant computational resources and memory bandwidth.

Finally, the outputs from the active experts are combined using a weighted sum, where the weights are derived from the normalized scores produced by the gating network. This allows the model to blend the specialized knowledge of different experts, giving more influence to those deemed most relevant by the router. The result is a single, cohesive output vector that reflects a dynamic, context-aware integration of multiple specialized sub-models.
