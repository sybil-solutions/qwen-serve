At the core of a Mixture-of-Experts (MoE) architecture is a lightweight gating network, often a simple linear layer, that evaluates the input representation for each token. This network calculates a set of scores or probabilities for every available expert, effectively determining how relevant each specialized sub-model is to the current context. These scores reflect the likelihood that a specific expert can best process the specific features of the token being analyzed.

Once the scores are computed, the model employs a routing strategy to select only a small subset of experts, typically the top-k highest-scoring ones, to actually perform the computation. This sparse activation ensures computational efficiency, as the model does not need to run all experts for every token. The selected experts process the input in parallel, generating their own distinct outputs based on their specialized training or parameter sets.

Finally, the outputs from the chosen experts are combined using the weights derived from the gating network’s initial scores. This weighted sum produces the final output for that layer, allowing the model to leverage the specialized knowledge of the most appropriate experts while ignoring the rest. This dynamic routing mechanism enables MoE models to scale capacity significantly without proportionally increasing the computational cost per token.
